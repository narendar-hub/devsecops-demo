# ShopKart DevSecOps Demo

A hands-on project to learn secure software development and delivery.

## Project Goals

- Build a simple web application
- Automate security checks with GitHub Actions
- Learn secret scanning, SAST, SCA, and IaC security
- Package the application with Docker
- Practice vulnerability discovery and remediation in a safe lab

## Security Principles

- Never commit real secrets or credentials
- Scan code and dependencies before release
- Review infrastructure changes before deployment
- Deploy only to authorized environments
